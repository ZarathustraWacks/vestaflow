Flow appearance

Appearance in the sidebar opens a compact background chooser. Clicking a palette or finish previews it; hovering only enlarges the thumbnail. Save choice persists a versioned preference for the selected broker in this browser. Cancel, Escape, the close button and backdrop clicks restore the latest saved preference. Selecting Use original Flow background restores the original canvas. A missing, invalid or unavailable preference uses the original background. Storage failures are visible and never reported as saved.

Six palettes coordinate the workspace background, cards, navigation, controls and action highlights. Classic pairs warm neutrals with teal; Gallery White pairs stone with petrol blue; Elm pairs parchment with aubergine; Pastel Bloom keeps its lavender background and pairs Cloud Tint (#F6F8FC) marble cards with Sky Mist (#DCEAF7) selections, Moonstone Blue (#B8C8D8) recommendation boxes, a dusty blue (#9AB0BD) sidebar and muted electric blue (#4D72C3) action accents; Coastal pairs cream with terracotta; Midnight pairs a light-charcoal (#626970) gunmetal marble sidebar with Cloud Tint (#F6F8FC) cards, pale blue-white (#E3EAF4) selections/recommendations and cool silver (#D8E2EB) controls on its existing mist canvas. Midnight links and small labels use dark ink for readability on white; its progress bars use charcoal for visible contrast. Three static finishes control the background texture independently. Urgency, errors, success and destructive actions keep their semantic colors. Original Flow restores the existing styling. Backgrounds use CSS with no images, dependencies, external calls or animation. Reduced-motion preferences suppress the small hover enlargement. The chooser is keyboard accessible and uses a native modal dialog.

Storage key: vesta.flow.appearance.v1.broker.<brokerId>. Preference storage is local to this browser and origin, not synced across devices. Broker changes close any open preview and load that broker's saved preference. Backgrounds never write to FUB, Render, action history, cadence clocks or appointment drafts. React background updates do not remount the workspace.
